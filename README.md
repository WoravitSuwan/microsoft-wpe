# เว็บรายงานข้อมูลคดีและ Case ID (แยกตามเจ้าของ)

เว็บสำหรับแปลงไฟล์ Excel ที่ export จากระบบ **thaipoliceonline** (เช่น `ค่าเริ่มต้น__20261116_083829.xlsx`)
ให้เป็นรายงานรูปแบบ **เอกสารแนบ_รายงานข้อมูลคดีและCaseID_<ยศ ชื่อ>.xlsx** โดยเก็บข้อมูลแยกตามเจ้าของ (พนักงานสอบสวน)

## รูปแบบรายงานที่ได้ (6 ชีต)

| ชีต | ที่มาของข้อมูล |
|---|---|
| สรุป | นับจากชีต 1.1–1.5 ด้วยสูตร COUNTA/COUNTIF + หมายเหตุอัตโนมัติ |
| 1.1 Case ID ทั้งหมด | ไฟล์ export thaipoliceonline |
| 1.2 สอบปากคำแล้ว | ทำเครื่องหมายในเว็บ หรือวางรายการ Case ID จาก CCMS ("มีสำนวนแล้ว") |
| 1.3 คดีอาญา (C.) | เลขคดีจาก thaipoliceonline + วางข้อมูลจากระบบ C. (CRIMES) |
| 1.4 ปรับปรุงข้อมูล C. | คำนวณอัตโนมัติ: คดีที่สถานะในระบบ C. ≠ สถานะจริง |
| 1.5 ค้างเกิน 6 เดือน | คำนวณอัตโนมัติ: สถานะจริง "ระหว่างสอบสวน" และรับคำร้องทุกข์เกิน 6 เดือน (กรอกศาล/เหตุผล/แนวทางในเว็บ) |

## การแยกข้อมูลตามเจ้าของ

- นำเข้าไฟล์ thaipoliceonline: หลังอัปโหลด ระบบแสดงรายชื่อพนักงานสอบสวนในไฟล์พร้อมจำนวนคดี ให้ **เลือกเฉพาะคนที่ต้องการ** (คนที่ไม่เลือกจะไม่ถูกนำเข้า)
  แล้วสร้างเจ้าของตามคอลัมน์ "พนักงานสอบสวน" ใส่แต่ละ Case ID ให้เจ้าของคนนั้น
- ผู้ดูแลระบบลบเจ้าของที่ไม่ต้องการได้หลายคนพร้อมกัน (ติ๊กเลือกในหน้าเจ้าของข้อมูลทั้งหมด → ลบเจ้าของที่เลือก)
- Case ID หนึ่งมีเจ้าของได้คนเดียว ผู้ดูแลระบบย้ายเจ้าของได้ (เช่น คดีที่ระบบยังระบุพนักงานสอบสวนคนเดิม) และการนำเข้าครั้งต่อไปจะไม่ย้ายกลับ
- บัญชี **พนักงานสอบสวน** ผูกกับเจ้าของ 1 คน: เห็น/แก้ไข/นำเข้า/ดาวน์โหลดได้เฉพาะข้อมูลของตัวเอง และย้ายคดีของคนอื่นมาเป็นของตัวเองไม่ได้
- บัญชี **ผู้ดูแลระบบ** เห็นทุกเจ้าของ สร้างผู้ใช้ และเลือกนำเข้าไฟล์ทั้งไฟล์ให้เจ้าของคนใดคนหนึ่งได้
- นำเข้าไฟล์ซ้ำได้: ข้อมูล thaipoliceonline จะอัปเดต ส่วนข้อมูลที่กรอกในเว็บ (1.2–1.5) ยังอยู่

## ให้พนักงานสอบสวนสมัครและใช้งานเอง (คนละบัญชี)

1. ผู้ดูแลระบบ → **ผู้ใช้งาน** → "ให้พนักงานสอบสวนสมัครสมาชิกเอง" → ตั้ง **รหัสลงทะเบียน** แล้วส่งลิงก์ + รหัสให้คนในกอง (ทางช่องทางภายใน)
2. แต่ละคนเปิดลิงก์ → **สมัครสมาชิก**: กรอก ยศ ชื่อ สกุล ให้ตรงกับคอลัมน์ "พนักงานสอบสวน" ใน thaipoliceonline
3. นำเข้าไฟล์ export (ไฟล์รวมของกองก็ได้) → ระบบติ๊กชื่อตัวเองไว้ให้ → ได้รายงานของตัวเอง
4. ดาวน์โหลด Excel แบบเอกสารแนบ

- 1 ชื่อ 1 บัญชี · เทียบชื่อแบบไม่สนช่องว่าง · ปิดรับสมัครได้ด้วยการลบรหัสลงทะเบียน
- **ลบข้อมูลของตัวเอง**: แท็บ "ตั้งค่ารายงาน" → ลบข้อมูลทั้งหมด (ยืนยันด้วยรหัสผ่าน) ลบเฉพาะคดีของตัวเอง
  เลือกลบบัญชีผู้ใช้ไปพร้อมกันได้ · ผู้ดูแลระบบลบคดีของใครก็ได้จากหน้าเดียวกัน

## เริ่มใหม่ / ล้างข้อมูลทั้งระบบ

- ระบบที่ยังไม่มีบัญชี: หน้า **เข้าสู่ระบบครั้งแรก** — ชื่อผู้ใช้/รหัสผ่านที่กรอก (ยืนยันรหัสผ่าน 2 ครั้ง) จะถูกบันทึกเป็นผู้ดูแลระบบ
- ผู้ดูแลระบบ → **ผู้ใช้งาน** → **ล้างข้อมูลทั้งระบบ** (พิมพ์ "ลบทั้งหมด" + รหัสผ่าน)
  - *เก็บบัญชีผู้ดูแลของฉันไว้* (แนะนำ): ลบคดี เจ้าของ ประวัติ ผู้ใช้อื่น และปิดรับสมัคร
  - *ลบทุกอย่างรวมบัญชีของฉัน*: กลับเป็นค่าเริ่มต้น การเข้าสู่ระบบครั้งแรกจะบันทึกเป็นผู้ดูแล
- ลืมรหัสผ่านผู้ดูแลทุกบัญชี: ล้างจาก Neon Console → SQL Editor ด้วย
  `TRUNCATE users, owners, cases, imports, uploads, settings;` แล้วเปิดเว็บ เข้าสู่ระบบครั้งแรกเพื่อตั้งผู้ดูแลใหม่

## ติดตั้งและเปิดใช้งาน

ต้องมี Python 3.10 ขึ้นไป

```bash
pip install -r requirements.txt
```

```bash
python -m caseapp
```

เปิด http://127.0.0.1:5000 — การเข้าสู่ระบบครั้งแรกจะบันทึกชื่อผู้ใช้/รหัสผ่านเป็นผู้ดูแลระบบ

ตัวแปรที่ตั้งได้:

- `DATABASE_URL` ถ้าตั้งเป็น `postgresql://...` จะใช้ Postgres แทน SQLite
- `CASEAPP_DB` ที่เก็บฐานข้อมูล SQLite (ค่าเริ่มต้น `instance/caseapp.sqlite3`)
- `SECRET_KEY` (ถ้าไม่ตั้ง ระบบสร้างและเก็บไว้ที่ `instance/secret_key`)
- `HOST` / `PORT` (ค่าเริ่มต้น `127.0.0.1` / `5000`; ใช้ในเครือข่ายภายในตั้ง `HOST=0.0.0.0`)

สำหรับใช้งานจริงหลายคน ควรรันผ่าน WSGI server เช่น `waitress-serve --call caseapp:create_app` หลัง HTTPS

## นำขึ้น Vercel

ไฟล์บน Vercel เป็นแบบชั่วคราว จึงต้องเก็บข้อมูลในฐานข้อมูล **Postgres** (Neon) แทน SQLite
โค้ดรองรับทั้งสองแบบ: ถ้ามี `DATABASE_URL` (หรือ `POSTGRES_URL`) จะใช้ Postgres อัตโนมัติ

1. vercel.com → **Add New… → Project** → Import repo `microsoft-wpe` (Framework Preset เลือกอะไรก็ได้ — `vercel.json` กำหนดเป็น Flask ไว้แล้ว) → Deploy
   (ครั้งแรกจะเห็นหน้า "ตั้งค่าระบบยังไม่ครบ" เป็นปกติ)
2. Project → **Storage** → Create Database → **Neon (Serverless Postgres)**
   - เลือก Region **Singapore (ap-southeast-1)** ให้ตรงกับฟังก์ชัน (`vercel.json` ตั้งไว้ที่ `sin1`)
   - Connect กับโปรเจกต์นี้ → ระบบเพิ่ม `DATABASE_URL` ให้เอง
3. Project → Settings → **Environment Variables** → เพิ่ม `SECRET_KEY` = ข้อความสุ่มยาว ๆ
   (สร้างได้ด้วย `python -c "import secrets; print(secrets.token_hex(32))"`)
4. Deployments → **Redeploy** → เปิดเว็บ → เข้าสู่ระบบครั้งแรก = บันทึกเป็นผู้ดูแลระบบ (ตารางในฐานข้อมูลสร้างให้อัตโนมัติ)

หมายเหตุ

- Vercel รับคำขอได้ไม่เกิน 4.5 MB ต่อครั้ง หน้าเว็บจึงแบ่งไฟล์อัปโหลดเป็นส่วนละ 2 MB อัตโนมัติ (รองรับไฟล์ถึง 60 MB)
- ทุกคนที่มี URL เปิดหน้าเข้าสู่ระบบได้ ข้อมูลคดีมีชื่อและเบอร์โทรผู้เสียหาย
  ควรตั้งรหัสผ่านที่แข็งแรง และตรวจสอบนโยบายการเก็บข้อมูลส่วนบุคคล (PDPA) ของหน่วยงานก่อนใช้งานจริง
- ถ้าต้องการจำกัดผู้เข้าถึงเพิ่ม ใช้ Vercel → Settings → **Deployment Protection**

## ทดสอบ

```bash
pip install -r requirements-dev.txt
```

```bash
python -m pytest -q
```

ทดสอบกับ Postgres ด้วย: ตั้ง `TEST_DATABASE_URL=postgresql://...` ก่อนรัน pytest

การทดสอบใช้ข้อมูลสมมติเท่านั้น — **ห้าม commit ไฟล์ Excel หรือฐานข้อมูลที่มีข้อมูลคดีจริง** (`.gitignore` กันไว้แล้ว)
