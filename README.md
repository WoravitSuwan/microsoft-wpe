# เว็บรายงานข้อมูลคดีและ Case ID (แยกตามเจ้าของ)

เว็บสำหรับแปลงไฟล์ Excel ที่ export จากระบบ **thaipoliceonline** (เช่น `ค่าเริ่มต้น__20261116_083829.xlsx`)
ให้เป็นรายงานรูปแบบ **เอกสารแนบ_รายงานข้อมูลคดีและCaseID_<ยศ ชื่อ>.xlsx** โดยเก็บข้อมูลแยกตามเจ้าของ (พนักงานสอบสวน)

## รูปแบบรายงานที่ได้ (6 ชีต)

| ชีต | ที่มาของข้อมูล |
|---|---|
| สรุป | นับจากชีต 1.1–1.5 ด้วยสูตร COUNTA/COUNTIF + หมายเหตุอัตโนมัติ |
| 1.1 Case ID ทั้งหมด | ไฟล์ export thaipoliceonline |
| 1.2 สอบปากคำแล้ว | ทำเครื่องหมายในเว็บ หรือวางรายการ Case ID จาก CCMS ("มีสำนวนแล้ว") |
| 1.3 คดีอาญา (C.) | เลขคดีจาก thaipoliceonline + วางข้อมูลจากระบบ C. (CRIMES) |
| 1.4 ปรับปรุงข้อมูล C. | คำนวณอัตโนมัติ: คดีที่สถานะในระบบ C. ≠ สถานะจริง |
| 1.5 ค้างเกิน 6 เดือน | คำนวณอัตโนมัติ: สถานะจริง "ระหว่างสอบสวน" และรับคำร้องทุกข์เกิน 6 เดือน (กรอกศาล/เหตุผล/แนวทางในเว็บ) |

## การใช้งาน (ไม่ต้องล็อกอิน)

1. ส่งลิงก์เว็บให้คนในกอง → เปิดแล้วใช้ได้เลย
2. **นำเข้าไฟล์ Excel** (ไฟล์ export thaipoliceonline ของตัวเองหรือไฟล์รวมของกอง) → เลือกชื่อตัวเอง
3. ได้รายงานแบบเอกสารแนบ กรอกข้อมูลข้อ 1.2–1.5 ในเว็บได้
4. **ดาวน์โหลด Excel**: ต้องกรอกชื่อผู้ดาวน์โหลดทุกครั้ง (บันทึกใน log)

- แต่ละเบราว์เซอร์มี **ชุดข้อมูลส่วนตัว** ของตัวเอง (เก็บใน cookie 1 ปี) คนอื่นที่เปิดลิงก์เดียวกันมองไม่เห็น
- **ลิงก์ส่วนตัว** (แท็บตั้งค่ารายงาน) ใช้เปิดข้อมูลชุดเดิมบนเครื่องอื่น — เก็บเป็นความลับ
- **ลบข้อมูลของตัวเอง**: แท็บตั้งค่ารายงาน → พิมพ์ "ลบ" → ลบเฉพาะชุดข้อมูลของตัวเอง (เลือกลบลิงก์ส่วนตัวด้วยได้)
- Case ID เดียวกันอยู่ได้หลายชุดข้อมูล (แต่ละคนนำเข้าไฟล์เดียวกันได้โดยไม่ชนกัน)

## ผู้ดูแลระบบ

- ปุ่ม **"🔒 เข้าสู่ระบบผู้ดูแล"** มุมขวาบน · ระบบที่ยังไม่มีผู้ดูแล: การเข้าสู่ระบบผู้ดูแลครั้งแรกจะบันทึกชื่อผู้ใช้/รหัสผ่าน (ยืนยัน 2 ครั้ง) เป็นผู้ดูแล
- เห็นทุกชุดข้อมูล ดาวน์โหลด/ลบได้ นำเข้าไฟล์แบบแยกตามชื่อพนักงานสอบสวนได้
- **บันทึกการใช้งาน**: เริ่มใช้งาน, นำเข้า, ดาวน์โหลด (ชื่อผู้ดาวน์โหลด), แก้ไข, ลบ, ผู้ดูแลเข้า/ออก,
  เข้าสู่ระบบไม่สำเร็จ, ล้างข้อมูล — พร้อมเวลา **IP จริง** และเบราว์เซอร์/อุปกรณ์
  - บน Vercel อ่าน IP จาก header ที่ Vercel ตั้งเอง (`x-vercel-forwarded-for`) ซึ่ง Vercel เขียนทับค่าที่ผู้ใช้ส่งมา จึงปลอมไม่ได้
  - ที่อื่นใช้ที่อยู่ของการเชื่อมต่อจริง ไม่เชื่อ `X-Forwarded-For` ที่ผู้ใช้ส่งมาเอง (วางหลัง proxy ของตัวเองให้ตั้ง `TRUST_PROXY=1`)
  - เป็น IP สาธารณะที่ผู้ใช้ออกอินเทอร์เน็ต (ถ้าอยู่หลังเครือข่ายเดียวกัน/VPN จะเห็นเป็น IP เดียวกัน)
- เข้าสู่ระบบผิดเกิน 10 ครั้งใน 15 นาทีจาก IP เดียวกัน จะถูกพักการเข้าสู่ระบบ

## เริ่มใหม่ / ล้างข้อมูลทั้งระบบ

- ผู้ดูแลระบบ → **ผู้ดูแลระบบ** → **ล้างข้อมูลทั้งระบบ** (พิมพ์ "ลบทั้งหมด" + รหัสผ่าน)
  - *เก็บบัญชีผู้ดูแลของฉันไว้* (แนะนำ): ลบคดีและชุดข้อมูลของทุกคน ประวัติ และผู้ดูแลคนอื่น (บันทึกการใช้งานเก็บไว้)
  - *ลบทุกอย่างรวมบัญชีผู้ดูแลของฉัน*: การกด "เข้าสู่ระบบผู้ดูแล" ครั้งแรกหลังจากนั้นจะบันทึกเป็นผู้ดูแลคนใหม่
- ลืมรหัสผ่านผู้ดูแลทุกบัญชี: Neon Console → SQL Editor →
  `TRUNCATE users, owners, cases, imports, uploads, settings;` (เพิ่ม `logs` ถ้าต้องการลบบันทึกการใช้งานด้วย)

## ติดตั้งและเปิดใช้งาน

ต้องมี Python 3.10 ขึ้นไป

```bash
pip install -r requirements.txt
```

```bash
python -m caseapp
```

เปิด http://127.0.0.1:5000 แล้วใช้ได้เลย · กด "เข้าสู่ระบบผู้ดูแล" ครั้งแรกเพื่อตั้งผู้ดูแลระบบ

ตัวแปรที่ตั้งได้:

- `DATABASE_URL` ถ้าตั้งเป็น `postgresql://...` จะใช้ Postgres แทน SQLite
- `CASEAPP_DB` ที่เก็บฐานข้อมูล SQLite (ค่าเริ่มต้น `instance/caseapp.sqlite3`)
- `SECRET_KEY` (ถ้าไม่ตั้ง ระบบสร้างและเก็บไว้ที่ `instance/secret_key`)
- `HOST` / `PORT` (ค่าเริ่มต้น `127.0.0.1` / `5000`; ใช้ในเครือข่ายภายในตั้ง `HOST=0.0.0.0`)

สำหรับใช้งานจริงหลายคน ควรรันผ่าน WSGI server เช่น `waitress-serve --call caseapp:create_app` หลัง HTTPS

## นำขึ้น Vercel

ไฟล์บน Vercel เป็นแบบชั่วคราว จึงต้องเก็บข้อมูลในฐานข้อมูล **Postgres** (Neon) แทน SQLite
โค้ดรองรับทั้งสองแบบ: ถ้ามี `DATABASE_URL` (หรือ `POSTGRES_URL`) จะใช้ Postgres อัตโนมัติ

1. vercel.com → **Add New… → Project** → Import repo `microsoft-wpe` (Framework Preset เลือกอะไรก็ได้ — `vercel.json` กำหนดเป็น Flask ไว้แล้ว) → Deploy
   (ครั้งแรกจะเห็นหน้า "ตั้งค่าระบบยังไม่ครบ" เป็นปกติ)
2. Project → **Storage** → Create Database → **Neon (Serverless Postgres)**
   - เลือก Region **Singapore (ap-southeast-1)** ให้ตรงกับฟังก์ชัน (`vercel.json` ตั้งไว้ที่ `sin1`)
   - Connect กับโปรเจกต์นี้ → ระบบเพิ่ม `DATABASE_URL` ให้เอง
3. Project → Settings → **Environment Variables** → เพิ่ม `SECRET_KEY` = ข้อความสุ่มยาว ๆ
   (สร้างได้ด้วย `python -c "import secrets; print(secrets.token_hex(32))"`)
4. Deployments → **Redeploy** → เปิดเว็บใช้ได้เลย · กด "เข้าสู่ระบบผู้ดูแล" ครั้งแรกเพื่อตั้งผู้ดูแล (ตาราง/การปรับฐานข้อมูลเดิมทำให้อัตโนมัติ)

หมายเหตุ

- Vercel รับคำขอได้ไม่เกิน 4.5 MB ต่อครั้ง หน้าเว็บจึงแบ่งไฟล์อัปโหลดเป็นส่วนละ 2 MB อัตโนมัติ (รองรับไฟล์ถึง 60 MB)
- ใครมีลิงก์ก็ใช้งานได้ (แต่เห็นเฉพาะชุดข้อมูลของตัวเอง) ข้อมูลคดีมีชื่อและเบอร์โทรผู้เสียหาย
  ส่งลิงก์ทางช่องทางภายใน ตั้งรหัสผ่านผู้ดูแลให้แข็งแรง และตรวจสอบนโยบาย PDPA ของหน่วยงานก่อนใช้งานจริง
- ถ้าต้องการจำกัดผู้เข้าถึงเพิ่ม ใช้ Vercel → Settings → **Deployment Protection**

## ทดสอบ

```bash
pip install -r requirements-dev.txt
```

```bash
python -m pytest -q
```

ทดสอบกับ Postgres ด้วย: ตั้ง `TEST_DATABASE_URL=postgresql://...` ก่อนรัน pytest

การทดสอบใช้ข้อมูลสมมติเท่านั้น — **ห้าม commit ไฟล์ Excel หรือฐานข้อมูลที่มีข้อมูลคดีจริง** (`.gitignore` กันไว้แล้ว)

## โครงสร้าง

```
caseapp/
  app.py        เส้นทางเว็บ, ระบบผู้ใช้, สิทธิ์ตามเจ้าของ
  db.py         ตาราง owners / users / cases (SQLite หรือ Postgres) และการ upsert ที่ไม่ลบข้อมูลที่กรอกเอง
  importer.py   อ่านไฟล์ thaipoliceonline และไฟล์รายงานเดิม
  report.py     คำนวณข้อ 1.1–1.5 และสร้างไฟล์ Excel ตามแบบเอกสารแนบ
  thaidate.py   แปลงวันที่ ค.ศ./พ.ศ. รูปแบบไทย
  templates/    หน้าเว็บ (ภาษาไทย)
app.py          จุดเริ่มต้นบน Vercel (ตัวแปร app)
vercel.json     ตั้งค่า Vercel (framework flask, region sin1)
tests/          ทดสอบด้วยข้อมูลสมมติ
```
